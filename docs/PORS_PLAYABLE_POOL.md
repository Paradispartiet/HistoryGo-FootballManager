# Pors: dokumentert historie og spillbar pool

Pors har 63 dokumenterte spillerkoblinger. 16 profiler har dokumentert posisjon og kan brukes i simuleringen. De øvrige 47 beholdes som source-thin historikkprofiler uten konstruerte posisjoner, roller, styrker eller taktisk tilpasning.

Klubbhistorikken skal derfor være komplett, mens tropp, oppstilling, trening og kamp bare kan bruke den posisjonsbelagte delmengden.
