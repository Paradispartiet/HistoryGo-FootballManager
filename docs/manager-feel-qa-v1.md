# Manager Feel QA Pass v1

Kort diagnose etter siste merge:

- Første skjerm hadde riktige elementer (klubbuke, neste kamp, prioritet og innboks), men ord som «Manager Portal», «Status» og «Oversikt» dro opplevelsen mot admin-dashboard i stedet for managerkontor.
- Navigasjonen var funksjonell, men romfølelsen ble svak fordi primærfanene blandet generiske navn («Oversikt», «Innboks», «Kamp») med managerrom. Dette er strammet til mot Kontor, Taktikkrom, Assistentråd, Kampdag, Stab, Klubb og Speiding.
- Lag-/taktikkvisningen hadde allerede grønn bane og spillerbrikker som hovedflate. Rester av Excel-følelse lå særlig i sekundærkortene («Status», «Detaljer», «Hva sier motoren?»). Disse er tonet mot kamptropp, spillerkort og analysevisning.
- Innboks/styre/stab fungerte teknisk, men trengte tydeligere fotballspråk. Copy er justert mot assistentråd, klubbapparat, kamptropp og styreforventning uten å endre dataflyt eller unlocks.
- Tabell-/analyseinnhold er beholdt som sekundært; førsteinntrykket skal nå være «jeg leder en klubb» med neste kamp og neste beslutning synlig øverst.
